# Еда — Android-дневник питания

Версия 1.0.2, Android 8.0 и новее. Приложение подключается через интернет.
Адрес по умолчанию: `https://food-consumption.solovyshka.com`. Резервный вход —
`https://vladislavsolovei.ru/food-consumption`. В настройках нужен код подключения,
который хранится на коробке в `/opt/secrets/food_checking/mobile.env`.
Ключ OpenAI и пароль базы в APK не входят.

Что работает:

- дневник по дням, завтрак/обед/ужин/перекус, сумма калорий;
- текст и запись микрофона до 2 минут; GigaAM на коробке, резервный Whisper;
- распознанный текст можно исправить перед расчётом;
- проверка порции, единицы и калорийности перед записью;
- добавление продуктов вручную, редактирование, удаление;
- маркировка оценок и значений с этикетки;
- повторное использование калорийности с этикетки для того же названия и единицы;
- черновик на телефоне и защита от дубликатов при повторном сохранении;
- обновление внутри приложения через OVH/RU с докачкой и проверкой подписи.

Типовые значения модели — оценка. Жирность сама по себе не определяет точную
калорийность конкретной марки молока. Для точного расчёта укажите значение
на 100 г/мл с упаковки и измеренную порцию. Название сохраняет жирность и марку.
Расчёт блюд использует настроенный на сервере OpenAI API. Подписка ChatGPT
для этих запросов не используется. Ручной ввод обходится без OpenAI.

## Сборка на коробке

Исходники: `/home/solovyshka/builds/food_checking/mobile`.
Flutter: `/home/solovyshka/develop/flutter/bin/flutter`.
Постоянная подпись: `/home/solovyshka/.config/food_checking/android-release.jks`.
Параметры подписи: `android-release.properties` в той же закрытой папке,
`android/key.properties` — ссылка на них. Секретные файлы не входят в репозиторий.
Без сохранения этого ключа нельзя выпускать совместимые обновления установленного APK.

```sh
cd /home/solovyshka/builds/food_checking/mobile
/home/solovyshka/develop/flutter/bin/flutter pub get
/home/solovyshka/develop/flutter/bin/flutter analyze
/home/solovyshka/develop/flutter/bin/flutter test
/home/solovyshka/develop/flutter/bin/flutter build apk --release
```

Результат: `build/app/outputs/flutter-apk/app-release.apk`.

## Сервер

Отдельный сервис `food-mobile-api`, файлы `app/mobile_api.py`,
`app/services/mobile_parser.py`, `app/db/mobile_models.py` и миграция
`0006_mobile_diary`. Миграция добавляет таблицы метаданных и защиты от повторов;
старые записи остаются в `consumption_entries`. Старые записи без метаданных
показываются как перекус с неизвестным источником калорийности.

Сервис работает с правами `solovyshka`, получает настройки от systemd и
использует текущую базу PostgreSQL на коробке. Запросы требуют токен,
выданный после ввода кода подключения. На телефоне токен и черновик
зашифрованы ключом Android Keystore; резервное копирование приложения отключено.
Публичные входы работают через HTTPS и отдельные SSH-туннели на коробку.
Домашний HTTP-адрес поддерживается как ручная настройка.

Перед установкой сервиса сделана резервная копия базы в
`/opt/food_checking/var/backups/mobile-20261003-094814/diary.dump`.
APK подписан, проверен анализатором Flutter и тестами интерфейса.
Микрофон на физическом Android-телефоне ещё предстоит проверить.

Публикация и последующие выпуски: [deploy/public/README.md](../deploy/public/README.md).
